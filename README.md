# การผลิตสื่อมัลติมีเดียด้วย AI

เว็บไซต์สื่อการเรียนรู้ออนไลน์สำหรับผู้เริ่มต้นสร้างสื่อดิจิทัลด้วยเครื่องมือปัญญาประดิษฐ์ สร้างด้วย Next.js, React, Tailwind CSS และ Framer Motion

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

จากนั้นเปิด [http://localhost:3000](http://localhost:3000)

## เนื้อหาและฟีเจอร์

- หน้า Landing Page แบบ responsive พร้อมการนำทางแบบ smooth scroll
- ความรู้พื้นฐานมัลติมีเดีย, AI Toolkit และเส้นทางบทเรียน
- วิดีโอประกอบจริง 3 คลิปใน `public/videos/` สำหรับ ChatGPT, Canva และ CapCut AI
- ค้นหาบทเรียน, FAQ, แบบฟอร์มติดต่อ และปุ่มกลับขึ้นด้านบน
- Dark/Light mode, scroll progress และ animation ด้วย Framer Motion
- ใช้ฟอนต์ Kanit และดีไซน์ glassmorphism ในโทนน้ำเงิน ม่วง และฟ้า

> ปุ่มดาวน์โหลดและเริ่มเรียนเป็น placeholder สำหรับต่อยอดกับระบบบทเรียนหรือไฟล์จริงได้ภายหลัง
